# 七个平台检查项底数

本文件是技能的底数库。只记录 2026 年 10 月 28 日对币安人生实测核实过的项目。平台改版后以当时页面为准。

## GoPlus

用 API 查，链 56 是 BSC 主网，链 97 是 BSC 测试网。地址是 `https://api.gopluslabs.io/api/v1/token_security/56?contract_addresses=<地址>`。返回 `result` 为空对象表示该链未收录，不是安全通过。

核实过的字段包括是否开源、是否代理、是否可增发、所有者地址、能否夺回所有权、是否蜜罐、买入税、卖出税、转账税、能否买入、能否全部卖出、滑点能否修改、个人滑点能否修改、是否黑名单、是否白名单、是否反鲸、反鲸能否修改、交易冷却、是否空投诈骗、能否自毁、外部调用、隐藏所有者、转账能否暂停、所有者能否改余额、是否同创建者蜜罐、是否在 DEX、持有人数、LP 持有人数、LP 总供应、DEX 池列表、前 10 持有人、LP 持有人。

## Honeypot.is

用 API 查，地址是 `https://api.honeypot.is/v2/IsHoneypot?address=<地址>&chainID=56`。核实过的字段包括是否蜜罐、买入税、卖出税、转账税、买入 Gas、卖出 Gas、模拟是否成功、风险等级与标记、抽样持有人分析、是否开源、是否代理、路由地址、交易对与流动性、交易对创建时间。

只做买卖模拟，不查增发、黑名单、代理升级等权限细节。模拟成功也不代表以后不会变。

## Token Sniffer

网页查，地址是 `https://tokensniffer.com/token/bsc/<地址>`。核实过的构成包括 0 到 100 评分、诈骗标记、买卖模拟、合约分析、持币分析、流动性分析、相似合约。

合约分析在实测中只显示三项，分别是已验证源码、所有权已放弃、创建者无特殊权限。持币分析包括创建者持仓是否低于 5%、其他持有人是否低于 5%、前 10 持有人是否低于 70%。流动性分析包括最大池、最大池流动性烧毁或锁定比例。相似合约在实测中为 11 条，相似度均为 100。

该平台未公开穷尽清单。不明确的项标未核实，不要写成无。

## Quick Intel

网页查，地址是 `https://app.quickintel.io/scanner`，也可直接用 `https://app.quickintel.io/?type=token&chain=bsc&contractAddress=<地址>`。实测共 27 项检查，汇总为 0 警告、21 良好、6 中性、0 注意。

核实过的项目包括蜜罐测试、LP 锁定、所有权已放弃、能否增发、交易税费、潜在隐藏所有者、隐藏地址、外部合约风险、可疑动作、外部动作、已知诈骗代码、能否增发、能否销毁、能否黑名单、多重黑名单、能否白名单、能否改最大钱包、能否改最大交易、能否暂停交易、交易冷却、能否改手续费钱包、能否桥接增发、能否改税费、能否盗走资金、能否绕过授权检查、授权是否被阻止、预生成合约地址、是否由诈骗钱包注资、是否代理、是否已验证、能否销毁、LP 已锁定或已烧毁。

## De.Fi Scanner

网页查，地址是 `https://de.fi/scanner`，扫描页是 `https://de.fi/scanner/contract/<地址>?chainId=bnb`。实测共 62 项，22 项 Detectors 加 40 项 General Detectors，全部为 0 问题。

22 项 Detectors 包括无漏洞提款函数、无重入风险、无锁定、已验证源码、合约不可升级、无 ERC20 授权漏洞、所有者不能滥用 ERC20 授权、无阻塞循环、钱包不能被拉黑、所有者不能暂停功能、无授权限制、无漏洞所有权函数、所有权不可找回、合约不是近期部署、部署者未用混币器、所有者钱包无既往诈骗、最近 30 天内有交互、极少撤销、初始化函数受保护、合约完好未自毁、时间锁不低于 24 小时、价格预言机用法合规。

40 项 General Detectors 包括编译器版本一致、无未检查调用、无漏洞自毁函数、无断言漏洞、无旧 Solidity 代码、无外部委托调用、无外部调用依赖、无漏洞认证调用、无无效字符、无 RTL 字符、无死代码、无风险数据分配、无未初始化状态变量、无未初始化存储变量、无漏洞初始化函数、无风险数据处理、无数字精度错误、无超范围数字漏洞、无映射数据删除漏洞、无重言式或矛盾、无错误真假值、无不准确除法、无多余构造函数调用、无漏洞转账、无漏洞返回值、无未初始化局部变量、无默认函数响应、无缺失算术事件、无缺失访问控制事件、无缺失零地址检查、无多余真假比较、无经函数调用可利用的状态变量、无漏洞底层调用、无无效 Solidity 版本、无昂贵循环、无不良数字写法、无缺失常量声明、无缺失外部函数声明、无漏洞应付函数、无漏洞消息值。

De.Fi 不提供相似合约、持仓分布和流动性金额。它的 62 项中没有可改余额一项，也没有 LP 锁仓一项。它的锁是指合约锁定，不是 LP 锁仓。

## CertiK Token Scan

网页查，地址是 `https://skynet.certik.com/tools/token-scan/bsc/<地址>`。实测共 23 项，0 Alerts、1 Attention、22 Passed。

23 项包括大户占比、是否开源、所有权是否未放弃、是否代理合约、是否有外部调用、是否可增发、能否自毁、能否夺回所有权、能否改余额、能否改税、是否有隐藏所有者、是否蜜罐、是否有黑名单、是否有白名单、转账是否可暂停、转账是否有冷却、是否反鲸、反鲸是否可改、买入税、卖出税、能否全部卖出、能否买入、能否提币。

## DappBay Risk Scanner

网页查，地址是 `https://dappbay.bnbchain.org/risk-scanner/<地址>`。它本身不是独立检测器，是聚合展示。页面标注 Security Services powered by Goplus、Certik、Hashdit。

三个标签分别转载 GoPlus、CertiK、HashDit 的结果，另有 Summary，包括持有人数、总量、前 10 持有人占比、所有者与创建者持仓、LP 持有人数与 LP 锁定比例。在清单中 DappBay 一律标转载，不要写成它自己独立查出这些项。HashDit 只在 DappBay 内出现，不要把它当作第八个平台。

## 覆盖盲区

重入、未检查调用、编译器不一致、未初始化变量等代码层问题，只有 De.Fi 成体系覆盖。

持仓分布只有 GoPlus、Token Sniffer、CertiK 有。流动性池与 LP 持有人只有 GoPlus、Token Sniffer、DappBay 的 Summary 有。

真实买卖模拟只有 Honeypot.is 和 Token Sniffer 的 Swap Analysis 有，后者的数据来源就是 Honeypot.is，属于同源数据，不要算成两家独立验证。

DappBay 的 GoPlus 标签与 GoPlus API 是同源数据，不要算成两家独立验证。
